# Референсы для сцены лавки

Сюда кладутся **исходные изображения**, из которых нарезаются спрайты сцены.
Это рабочие исходники, а не ассеты сайта — в сборку они не попадают.

## Что положить

| Имя файла | Что это |
| --- | --- |
| `shop.png` (или `.jpg`/`.webp`) | Интерьер лавки: фишай-комната, баннер с каллиграфией, свитки, карты, компас, прилавок |
| `merchant.png` (или `.jpg`/`.webp`) | Торговец на ровном светлом фоне, в полный рост |

Имена важны — по ним пайплайн находит исходники. Разрешение — максимальное,
какое есть: чем крупнее оригинал, тем чище нарезка.

## Как передать

**Вариант 1 — через репозиторий (надёжный):**

```bash
# положить файлы в assets/reference/, затем:
git add assets/reference/
git commit -m "Add scene reference images"
git push
```

**Вариант 2 — прикрепить файлами в чат.** Именно как файлы (через `@`), а не
вставкой картинки в сообщение: вставленное изображение видно в диалоге, но не
сохраняется на диск, и нарезать его нельзя.

## Что происходит дальше

1. У торговца удаляется ровный фон → прозрачный PNG.
2. Из интерьера вырезаются отдельные объекты (баннер, висящие свитки, карты,
   компас, фонарь, сундук, товары на прилавке) — каждый становится своим слоем.
3. Слои собираются в сцену и анимируются по отдельности.

Готовые спрайты складываются в `src/assets/scene/` и уже участвуют в сборке.
